# Instructions for AI agents

To use `neev-cli` on a user's behalf, read [`docs/ai-agents.md`](./docs/ai-agents.md)
first and follow it: the pre-flight checks, the rules for working without a terminal,
a recipe for each product (Sandboxes, Agents, AI runtimes, Account), the JSON output
shapes, and what to do about each error.

Raw copy: https://raw.githubusercontent.com/NeevCloudAI/neev-cli/main/docs/ai-agents.md

For any command not covered there, run `neev-cli <command> --help`, or see the
[command reference](./docs/command-reference.md).
